# Glossary

- **Cybersecurity**: protecting computers, data and networks from harm. Example: a password on your phone.
- **Red team**: ethical attackers who test defenses with permission. Example: a hired tester trying to break in.
- **Blue team**: defenders who monitor, detect and fix. Example: a guard watching cameras.
- **Purple team**: red and blue working together so each attack improves detection. Example: tester and guard reviewing each attempt.
- **Authorization**: written permission to test a system. Example: a signed contract before a locksmith tests your doors.
- **Scope**: the list of what you are allowed to test. Example: only the front door, not the neighbors' doors.
- **CIA triad**: confidentiality, integrity, availability. Example: private chat, unedited bank record, working website.
- **Git**: a tool that records every version of your files. Example: a binder with every draft.
- **GitHub**: a website that stores Git projects online. Example: a public bookshelf for your binders.
- **Repository (repo)**: one project folder tracked by Git.
- **2FA**: a second proof, besides your password, to log in. Example: a key plus a fingerprint.
- **.gitignore**: a file listing what Git must not upload. Example: a "do not mail" pile.
